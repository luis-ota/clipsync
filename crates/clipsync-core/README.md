# clipsync-core

Core protocol and transport library for [clipsync](https://github.com/luis-ota/clipsync),
a secure clipboard synchronizer for Android and desktop systems.

The crate contains the wire protocol, pairing, TLS pinning, relay encryption,
clipboard payload validation and bounded binary transfer primitives.

The end-user daemon and platform clients are distributed through the
[clipsync releases](https://github.com/luis-ota/clipsync/releases).
